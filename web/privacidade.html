Política de privacidade do Arvertes Studio

Esta política descreve como o Studio Web trata os dados da conta, os dados salvos no navegador e os arquivos usados pela integração opcional com o Google Drive.

Conta e dados do Studio

O login do Studio usa GitHub via Supabase Auth. O backend usa o identificador da conta para autenticar as solicitações e separar seus registros dos registros de outras contas. No modo autenticado, conversas, memória, dossiês textuais, revisões e informações de produção são armazenados no PostgreSQL do Supabase. O frontend é hospedado na Vercel e a API, no Render.

O modo local mantém seus registros no armazenamento do navegador. A troca entre os modos conserva os dados onde foram gravados.

Integração com o Google Drive

Quando a integração é ativada, o operador autoriza o escopo drive.file e seleciona, com o Google Picker, as pastas privadas Arvertes e Personagens. O escopo limita o acesso do aplicativo aos arquivos e pastas que ele cria ou que são selecionados para uso com ele.

O Studio usa o acesso para conferir as pastas autorizadas, gravar e recuperar anexos de personagens e arquivar pacotes ZIP quando solicitado. O backend usa identificadores, tamanho e SHA-256 para localizar os arquivos e verificar a integridade. Os arquivos ficam no Drive. O banco guarda referências aos arquivos e informações necessárias para apresentá-los no Studio.

As credenciais do Drive são mantidas na configuração protegida do servidor quando a integração está ativa. A API processa o conteúdo necessário à operação solicitada, como recuperar um anexo ou montar um ZIP. O uso dos dados do Google é limitado às funções descritas nesta seção.

Acesso, retenção e remoção

É possível exportar seus dossiês pelo Studio. A remoção de um anexo no Studio desvincula o arquivo da revisão atual. A exclusão de um dossiê remove o conteúdo de suas revisões do Studio. Os arquivos correspondentes permanecem no Drive até que seu proprietário os remova naquele serviço.

O proprietário pode revogar a autorização na página de conexões da conta Google. A revogação encerra o acesso concedido ao aplicativo. Os arquivos no Drive e os registros do Studio podem ser gerenciados separadamente.

Contato sobre privacidade

Para dúvidas sobre a integração ou pedidos sobre seus dados, use o e-mail de suporte exibido na tela de consentimento do Arvertes Studio no Google.
